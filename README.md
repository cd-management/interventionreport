# Relatório de Intervenção – DIGIWEST

Página web de relatório de intervenção técnica da **Digiwest**, gerada em HTML e publicada via GitHub Pages.

## Acesso

🔗 **[Ver Relatório](https://seuutilizador.github.io/digiwest-relatorio/)**

> Substitui o link acima pelo URL gerado após ativar o GitHub Pages nas definições do repositório.

## Conteúdo

- `index.html` — Relatório de intervenção completo (autocontido, sem dependências locais)

## Como publicar (GitHub Pages)

1. Faz upload do ficheiro `index.html` para este repositório
2. Vai a **Settings → Pages**
3. Em *Source*, seleciona o branch `main` e a pasta `/ (root)`
4. Clica em **Save**
5. Aguarda 1–2 minutos — o link ficará disponível em `https://seuutilizador.github.io/nome-do-repositorio/`

## Tecnologia

- HTML5 + CSS3 inline (sem frameworks externas)
- Fontes: [DM Sans & DM Mono](https://fonts.google.com/) via Google Fonts
- Compatível com qualquer browser moderno
